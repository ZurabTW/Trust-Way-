# Trust Way

Внутренние программы Trust Way (Шэньчжэнь): выкуп и доставка товаров из Китая в Россию.

| Файл | Что это |
|---|---|
| `apps/uchet.html` | «Trust Way · Учёт» — сделки, оплаты клиентов, расходы, кошельки (Россия / Китай), касса менеджеров, процент менеджеров |
| `apps/poisk.html` | «Поиск товара» — заявки на поиск от менеджеров в России к менеджеру в Китае, найденные варианты, отчёт по времени работы (RU / 中文) |
| `apps/nakladnaya.html` | «Накладная Trust Way» — накладная клиенту на доставку с процентом сверх ставки перевозчика, выгрузка в PNG / PDF / Excel |

## Важно

`uchet.html` и `poisk.html` написаны как страницы Claude (artifacts): база данных, пользователи, фото и перевод
берутся из среды Claude через `window.claude.use("db" | "user" | "assets" | "sample")`.
Если открыть файл просто в браузере, страница покажет «Откройте страницу в Claude».
Чтобы программы работали отдельно от Claude, нужно заменить эти вызовы на свой сервер и базу данных.

`nakladnaya.html` работает и сама по себе в браузере, кроме кнопок скачивания (они используют `downloads` из Claude).
